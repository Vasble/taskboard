
## Лабораторна 4

1. Після `git add` файл переходить з Untracked / Changes not staged у зелений список Changes to be committed, тобто потрапляє в індекс і буде в наступному commit.
2. `git diff` показує різницю між робочими файлами й останнім commit: рядки з `+` додані, з `-` видалені.
3. `git switch main` лише перемикає на гілку main, а `git merge` вливає зміни іншої гілки в поточну.
4. Конфлікт виник, бо в гілках main і ukr-title по-різному змінили той самий рядок `<h1>`. Я залишив об'єднаний варіант «Дошка завдань: керуй завданнями», видалив службові рядки й зробив commit.
